## Terminology

- **Artifact identity:** reviewers signed a digest-bound description of exact artifact bytes.
- **Runtime certification:** approved evidence binds an exact runtime/material closure and execution profile.
- **Release approval:** the release gate accepted exact evidence and subject bytes.
- **Published:** a signed release is present in the registry; this does not prove it is loaded.
- **Activated:** an approved deployment selected exact release/runtime identity.
- **Available:** current registry verification, team authorization, and an identity-bound serving upstream all pass.

Never collapse these into an unqualified “approved”, “verified”, “green”, or “active” badge.
