Discover certified models and manage each team's allow-list and default. Policy set here is what the [harness gateway](/docs/gateway) enforces at call time.

<Note tag="Authoritative schema">
  Field shapes below mirror the gateway's model objects; the exhaustive policy schema is in `/openapi.json`. Admin model routes require an owner or admin role.
</Note>

<RouteIndex page="models" />

## Route inventory

| Method | Route | Purpose |
| --- | --- | --- |
| `GET` | `/v1/admin/models` | List certified models the org may allow. |
| `GET` | `/v1/admin/model-policies?team={team}` | Read a team's allow-list and default model. |
| `PUT` | `/v1/admin/model-policies?team={team}` | Set a team's allow-list and default model. |

## Certified models

<Method method="GET" path="/v1/admin/models" returns="200" />

The certified catalog. Each model carries a verification state — only `certified` / `trusted` models may be added to a team allow-list.

<EndpointMeta>Auth · **owner / admin**</EndpointMeta>

```bash
curl https://api.s46.dev/v1/admin/models \
  -H "Authorization: Bearer $S46_ACCESS_TOKEN"
```

```ts
const { data } = await fetch("https://api.s46.dev/v1/admin/models", {
  headers: { Authorization: `Bearer ${accessToken}` },
}).then((r) => r.json());
```

```py
models = requests.get("https://api.s46.dev/v1/admin/models",
                      headers={"Authorization": f"Bearer {access_token}"}).json()
```

```json
{
  "data": [
    {
      "id": "s46/devstral-small-2-24b",
      "displayName": "Devstral Small 2 24B",
      "ownedBy": "sovereign46",
      "certified": true,
      "published": true,
      "verificationState": "trusted"
    }
  ]
}
```

## Team model policy

<Method method="GET" path="/v1/admin/model-policies?team={team}" returns="200" />
<Method method="PUT" path="/v1/admin/model-policies?team={team}" returns="200" />

A team's `allow` list determines which models the gateway will serve for that team; `default` is used when a gateway request omits `model`. A request for a model outside the allow-list fails at the gateway with `403 model_not_allowed`.

<EndpointMeta>Auth · **owner / admin** · Schema · **illustrative**</EndpointMeta>

```bash
# Read the current policy
curl "https://api.s46.dev/v1/admin/model-policies?team=%40s46%2Fengineering" \
  -H "Authorization: Bearer $S46_ACCESS_TOKEN"

# Set the allow-list and default
curl -X PUT "https://api.s46.dev/v1/admin/model-policies?team=%40s46%2Fengineering" \
  -H "Authorization: Bearer $S46_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "default": "s46/devstral-small-2-24b",
    "allow": ["s46/devstral-small-2-24b"]
  }'
```

```ts
await fetch(
  "https://api.s46.dev/v1/admin/model-policies?team=%40s46%2Fengineering",
  {
    method: "PUT",
    headers: { Authorization: `Bearer ${accessToken}`, "Content-Type": "application/json" },
    body: JSON.stringify({
      default: "s46/devstral-small-2-24b",
      allow: ["s46/devstral-small-2-24b"],
    }),
  },
);
```

```py
requests.put(
    "https://api.s46.dev/v1/admin/model-policies",
    params={"team": "@s46/engineering"},
    headers={"Authorization": f"Bearer {access_token}"},
    json={"default": "s46/devstral-small-2-24b",
          "allow": ["s46/devstral-small-2-24b"]},
)
```

```json
{
  "team": "@s46/engineering",
  "default": "s46/devstral-small-2-24b",
  "allow": ["s46/devstral-small-2-24b"]
}
```

<Note tag="Resolution">
  Consumers should read the effective list from `GET /v1/teams/{team}` (`defaultModel` + `models`) rather than hard-coding model ids.
</Note>
