## Liveness

<Method method="GET" path="/healthz" returns="200" />

Reports process liveness, not model availability:

```json
{ "status": "ok" }
```

## Readiness

<Method method="GET" path="/readyz" returns="200 / 503" />

```bash
curl -i https://api.s46.dev/readyz
```

Readiness requires a reachable database when configured, current independent registry verification, and current serving authority when enabled. Serving-authority readiness includes a matching persisted authority snapshot, valid deployment and activation, a fresh challenged loaded identity, protected route consistency, at least one trusted exact-release grant, and enough remaining monthly capacity for its signed worst-case reservation.

| HTTP | Body | Meaning |
| --- | --- | --- |
| `200` | `{ "status": "ok", "database": "ok", "modelRegistry": "ok", "servingAuthority": "ok" }` | Configured checks passed. |
| `200` | `{ "status": "ok", "database": "disabled", "modelRegistry": "ok", "servingAuthority": "ok" }` | No database is configured; applicable model checks passed. |
| `503` | `{ "status": "unavailable", "database": "unavailable" }` | Database check failed; model checks were not reached. |
| `503` | `{ "status": "unavailable", "database": "ok", "modelRegistry": "unavailable", "servingAuthority": "unavailable" }` | Registry verification failed; `database` can also be `disabled`. |
| `503` | `{ "status": "unavailable", "database": "ok", "modelRegistry": "ok", "servingAuthority": "unavailable" }` | Registry is current, but serving authority, an exact grant, or worst-case capacity is unavailable. |

Readiness failures use this status body, **not** the JSON error envelope. `/healthz` remains liveness-only. A source implementation or future readiness `200` does not itself prove historical production deployment; inspect current authority metadata and retain same-window inference/accounting evidence.

Policy and evidence provisioning belongs in the API operator runbooks. See [Serving authority](/docs/serving-authority) for the public contract and [Model assurance status](/docs/model-status) for the dated production observation.
